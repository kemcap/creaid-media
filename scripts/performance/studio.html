CreAid · Performance Engine / 1.4

Performance Studio.

Lokales Konfigurationsstudio für statische Websites. Keine Serververbindung, keine automatische Veröffentlichung.

01 / Profil wählen

Ein Profil setzt nur die Modulauswahl zurück. Dateilisten bleiben erhalten; Änderungen sind individuell möglich.

02 / Module konfigurieren

Erlaubt: deferScripts, preloadFonts, preloadImages. Keine Interaktionsverzögerung.

03 / Audit-Budgets

Interne Warnschwellen, keine Google-Grenzwerte. Werte in KiB.

04 / Konfiguration exportieren

Die exportierte Datei im Projektordner ablegen und den geprüften Vorschau-Build starten:
npm run performance:pipeline -- dist performance-v14 performance-config.json .performance-tools
Der Toolordner wird nur für optionale Minifizierung und Bildgenerierung benötigt. Das Studio startet keine Shell-Befehle und prüft nicht, ob die eingegebenen Dateien existieren. Der Build validiert diese separat.


Kein Login, kein Tracking, kein Upload. Nur Konfigurationsexport. Alle Ausgaben bleiben lokal; Produktionsfreigabe und Hosting-Abnahme erfolgen separat.
