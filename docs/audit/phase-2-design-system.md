# Phase 2 – Globales Designsystem (erster Schritt)
Baseline: 236 dunkle Sektionsdarstellungen in 196 Ansichten, 166 ohne Fadenkreuz (Phase-0-Lauf 45473642303). Phase-1-Lauf 45484593383 scheiterte an einer veralteten Assertion, die entferntes Journal-Scroll-Scrubbing weiterhin verlangt. Die Assertion wird durch einen gezielten Schutz gegen Wiedereinführung der entfernten Animation ersetzt; übrige Qualitätsgates bleiben bestehen.
Implementiert: gemeinsame CSS- und JS-Steuerung für dunkle Inhaltssektionen anhand tatsächlicher Hintergrundfarbe; Homepage-Achsen wiederverwendet, alte separate Homepage-Interaktionslogik entfernt, vorhandenes Spezialseiten-Ornament bei aktiver gemeinsamer Dekoration ausgeblendet. Keine Fadenkreuze in Karten, Navigation oder Bedienelementen. Dekorativ und ohne Pointer-Blocking, reduzierte Bewegung und Touch-Verhalten erhalten. Bereits vorhandene No-JS-Dekorationen bleiben; neue dynamisch erkannte Bereiche benötigen aktuell JavaScript für das Fadenkreuz. Statische Markierung/No-JS-Fallback für weitere Bereiche bleibt als Folgeschritt offen.
Prüfung: 98 Routen x 2 Viewports; dunkle Flächen, genau ein sichtbares Fadenkreuz, aria-hidden, pointer-events:none, Größe, Header/Footer, Overflow, HTTP/JS-Fehler. Screenshots für repräsentative Seiten.
Weitere Phase-2-Arbeiten offen: komponentenbezogene Bestandsaufnahme und Konsolidierung der Typografie, Abstände, Buttons, Karten, Formulare, Icons und Raster; keine pauschalen ungetesteten Style-Overrides. Keine Änderungen an main, IONOS oder Produktionsdomain. Testergebnisse ausstehend.
